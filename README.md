# syspulse

Modern, high-performance system health and network diagnostic CLI tool.

## Installation

```bash
pip install git+https://github.com/AmhetCnaa/syspulse.git
```

## Usage

Interactive Live Monitor:
```bash
syspulse
```

One-shot Snapshot:
```bash
syspulse --snapshot
```

JSON Export:
```bash
syspulse --json
```
